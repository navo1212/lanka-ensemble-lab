Can ensemble learning forecast tomorrow's temperature in Colombo? One real dataset, every major ensemble idea: Bagging, Boosting, Stacking and hybrid models.

4,322

Period

How the ensemble families work

Bagging 🌳🌳🌳 → average

Many deep trees trained in parallel on bootstrap samples; averaging cancels their mistakes → reduces variance. Random Forest, Extra Trees.

Boosting 🌱→🌿→🌳 sequential

Small trees built one after another, each fixing the previous errors → reduces bias. XGBoost, LightGBM, Gradient Boosting, AdaBoost.

Stacking & hybrids 🧠

Different models combined: a meta-model learns whom to trust, or ARIMA + Random Forest split the work (linear season vs non-linear weather).

💡 Innovation: errors by monsoon season, and a live Tomorrow in Colombo forecast with an 80% range, a heat alert and a rain what-if.

Data: real daily weather for Colombo (6.93°N, 79.86°E) from the Open-Meteo historical archive (ERA5 reanalysis). Target: tomorrow's daily mean temperature, using only information up to today. Test set: the last 365 days (Nov 2025 – Oct 2026).

🌲 vs 🚀 Random Forest vs XGBoost

What this shows

Random Forest reaches its best error quickly and then stays flat — more trees only average more; they never over-fit.
XGBoost starts far off (learning rate 0.03 = small steps), improves tree by tree — boosting reduces bias — and is best at 200 trees (0.596 °C). With more trees it slowly gets worse (0.613 °C at 600): boosting over-fits if it runs too long, so it needs early stopping or a tuned number of trees.

Each fold trains on all earlier years and tests on the following year — no future data leaks into training. This page uses lighter settings (5 folds, 200 trees) so it loads fast.

ℹ️ Research & About
Random Forest vs gradient boosting
	Random Forest	XGBoost	LightGBM	CatBoost
Trees built	independent, deep, bootstrap	sequential, depth-wise, regularised	sequential, leaf-wise, histograms	sequential, symmetric trees, ordered boosting
Mainly reduces	variance	bias	bias	bias
Tuning	minimal	moderate	moderate	minimal
Over-fit risk	low	medium	medium–high on small data	low

Time series: trees cannot extrapolate a trend or unseen temperatures — that is why the ARIMA + RF hybrid lets ARIMA handle trend and season.

Tabular vs image / text data
Tabular: tree ensembles remain state-of-the-art for medium tabular data — mixed types, thresholds, interactions, little preprocessing.
Images / text: signal lives in spatial/sequential structure → CNNs / Transformers dominate; ensembles are used on their embeddings or to average networks.
Data

One real dataset: Colombo daily weather 2015–2026 from the Open-Meteo historical archive (ERA5 reanalysis), saved in data/colombo_weather_daily_used.csv.
